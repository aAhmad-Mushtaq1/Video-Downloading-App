## 📱 Screens Overview

### 1. Home Screen
**Purpose**: Video URL input and preview

**Features**:
- ✨ Large URL input field with glow animation on focus
- 📋 One-tap paste from clipboard
- 🔍 Auto-detect platform from URL
- 🖼️ Video preview card with thumbnail
- 📊 Video metadata display (title, author, duration)
- 🎯 Quality selector with file size preview
- 📦 Format selector (MP4, MKV, WEBM, MP3)
- ⬇️ Large gradient download button

**User Flow**:
1. Paste or type video URL
2. Click "Fetch Video Info"
3. See skeleton loading animation
4. Preview video details
5. Select quality and format
6. Click download button

---

### 2. Downloads Screen
**Purpose**: Monitor active downloads

**Features**:
- 📊 Real-time progress tracking
- 🎯 Progress percentage and speed
- ⏱️ ETA (Estimated Time Remaining)
- 🖼️ Video thumbnail preview
- ⏸️ Pause button for active downloads
- ▶️ Resume button for paused downloads
- ❌ Cancel button to stop downloads
- 🧹 Clear completed downloads

**Visual Elements**:
- Animated circular or linear progress bars
- Download speed in MB/s
- Downloaded size / Total size
- Status indicators (downloading, paused, completed, failed)

---

### 3. History Screen
**Purpose**: Browse completed downloads

**Features**:
- 🔍 Search functionality
- 📅 Sorted by date (newest first)
- 🖼️ Grid view on desktop, list on mobile
- 📊 File information (quality, format, size, date)
- 🎬 Open file action
- 📁 Open folder action
- 🗑️ Delete from history
- 🧹 Clear all history

**Interactive Elements**:
- Swipe to delete (mobile)
- Hover actions (desktop)
- Pull to refresh (mobile)
- Confirmation dialogs for destructive actions

---

### 4. Settings Screen
**Purpose**: App configuration

**Features**:
- 🌓 Dark/Light theme toggle with smooth transition
- 🎯 Default video quality selection
- 📦 Default format selection
- ⚡ Concurrent downloads limiter (1-5)
- 📁 Download location picker
- 💾 Storage usage display
- ℹ️ App version and about
- 📄 Licenses viewer
- 🔗 GitHub repository link
